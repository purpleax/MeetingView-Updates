# MeetingView updates

Signed, notarized builds of MeetingView and its Sparkle update feed (`appcast.xml`).

Download the latest disk image from [Releases](https://github.com/purpleax/MeetingView-Updates/releases/latest), open it and drag MeetingView to Applications. Installed copies check this feed and update themselves.
