# MeetingView

MeetingView is a macOS menu-bar app that shows your current or next meeting and joins it in one click. It works with every calendar in the macOS Calendar app and with 60+ meeting services, including Zoom, Google Meet, Microsoft Teams and Webex.

This repository holds signed, notarized builds of MeetingView and its update feed (`appcast.xml`).

## Download

Download the latest disk image from [Releases](https://github.com/purpleax/MeetingView-Updates/releases/latest), open it and drag MeetingView to Applications. It needs macOS 12 or later. Installed copies check for updates once a day and update themselves.
